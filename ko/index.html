Flaspek이란?

Flaspek은 iPhone을 표지판으로 바꿔 줍니다. 말하면 내 말이 거대한 글씨로 화면을 가득 채웁니다. LED 전광판처럼 흐르는 글자, 한 번에 한 단어씩 큰 글씨, 또는 여러 줄 고정 포스터. 타이핑은 필요 없습니다.

멀리서도 눈에 띄거나 읽혀야 하는 순간을 위해 만들었습니다. 콘서트나 경기장, 입국장, 마중 자리, 시끄러운 바, 어두운 방, 차창, 그리고 내 말을 들을 수 없는 사람과의 대화.

사용 방법

  1. 말하세요. 마이크를 탭하고 메시지를 말하세요. 잘못 인식됐나요? 텍스트 아래의 언어 캡슐을 탭하면 다른 언어로 다시 녹음됩니다.
  2. 보여 주세요. ‘표시’를 탭하세요. 표지판이 최대 밝기로 전체 화면에 펼쳐집니다. 핀치로 크기 조절, 위아래로 드래그해 속도 변경, 아래로 스와이프해 종료.
  3. 계속 말하세요. ‘라이브’를 탭하면 말하는 대로 단어가 바로 표지판에 나타납니다. AirPods를 꾹 눌러 화면을 건드리지 않고 새 줄을 시작하세요.

세 가지 표시 방식: 스크롤(클래식 흐르는 글자, 어느 방향으로든 또는 왕복), 단어별(한 단어씩 가운데에, 움직이면서도 읽기 쉬움), 쌓기(화면에 맞게 저절로 조절되는 고정 포스터). 효과: 글로우, 네온, 무지개, 펄스, 깜박임, 불꽃, 잔상. 원탭 프리셋 12가지: 콘서트, 스포츠, 공항, 마중, 야외, 대화, 사랑, 파티, 네온, SOS, 미니멀, MAX.

자주 묻는 질문

iPhone에서 흐르는 글자 표지판을 만들려면?

Flaspek을 열고 마이크를 탭한 뒤 메시지를 말하고 ‘표시’를 탭하세요. 텍스트가 최대 밝기로 화면 전체를 가로질러 흐르며, 방 건너편이나 인파 너머에서도 읽을 수 있을 만큼 큽니다. 핀치로 크기 조절, 위아래로 드래그해 속도 변경, 아래로 스와이프해 종료.

Flaspek은 무료인가요?

네. 모든 스타일, 효과, 라이브 모드, 즐겨찾기는 무료입니다. 무료 버전은 하루(달력 기준)에 2회 표시할 수 있습니다. 표시란 새 메시지를 전체 화면으로 띄우는 것이고, 같은 메시지를 다시 표시하는 건 무료입니다. Flaspek Pro는 주간 구독 또는 한 번만 결제하는 평생 이용권으로 하루 제한을 없애 줍니다. 가격은 앱 안과 내 국가의 App Store에 표시됩니다.

라이브 모드란?

‘라이브’를 탭하고 표지판이 이미 화면에 켜진 상태에서 말하세요. 말하는 대로 단어가 바로 나타나기 때문에, 휴대폰을 머리 위로 든 채 계속 이야기할 수 있습니다. 약 8초간 조용하면 녹음이 저절로 멈춥니다. ‘다시 시작’을 탭하거나 AirPods를 꾹 눌러 새 줄을 시작하세요.

음성 인식이 되지 않아요

설정 → Flaspek에서 마이크와 음성 인식이 허용되어 있는지 확인하세요. 음성 인식은 Apple이 제공하며 대부분의 언어에서 인터넷 연결이 필요합니다. 문장이 잘못 인식됐다면 텍스트 아래의 언어 캡슐 중 하나를 탭해 다른 언어로 다시 녹음하세요.

AirPods 리모컨이 작동하지 않아요

AirPods 제어는 실제 iPhone에서 라이브 모드일 때만 작동합니다. 스템을 꾹 눌러(한 번, 두 번, 세 번 누르기 모두 가능) 새 줄을 시작하세요. AirPods가 연결되어 있고 라이브 세션이 진행 중인지 확인하세요. 먼저 ‘라이브’를 한 번 탭한 다음 꾹 누르면 됩니다.

표지판에 문장 부호와 기호를 넣으려면?

문장 부호를 소리 내어 말하세요. "comma", "period", "question mark", "exclamation mark". 기호도 마찬가지로 "heart sign", "star sign", "arrow sign"이라고 말하면 ♥ ★ → 가 됩니다. 음성 문장 부호 명령은 현재 영어와 러시아어로 인식됩니다. 영어 받아쓰기에는 Apple이 자동으로 문장 부호도 넣어 줍니다.

어떤 언어를 지원하나요?

음성 인식은 16개 언어에서 작동합니다: English, 中文, हिन्दी, Español, Français, العربية, Português, Русский, Bahasa Indonesia, Deutsch, 日本語, Türkçe, 한국어, Italiano, Українська, Polski, 그리고 기기 언어를 따르는 ‘자동’. 앱 인터페이스는 15개 언어로 현지화되어 있습니다.

Flaspek은 오프라인에서도 되나요?

표지판 자체는 완전히 오프라인으로 작동합니다. 음성 인식은 해당 언어의 온디바이스 음성 모델이 iPhone에 설치되어 있지 않은 한 인터넷 연결이 필요합니다. 메시지를 직접 입력하는 건 언제나 오프라인으로 됩니다.

표지판을 다른 언어로 번역하려면?

전체 화면에서 … 메뉴를 열고 ‘번역할 언어…’를 선택하세요. 표지판이 선택한 언어로 표시되며, 라이브 모드로 말하는 도중에도 번역됩니다. 처음에는 iOS가 언어 팩 다운로드를 요청할 수 있습니다.

메시지를 저장하고 다시 쓰려면?

받아쓰기가 끝나면 ‘표시’ 옆의 하트 버튼을 탭하세요. 메시지가 현재 스타일과 함께 저장됩니다. 홈 화면의 하트 버튼은 ‘즐겨찾기’와 ‘최근’을 엽니다. 마지막으로 표시한 메시지 20개는 자동으로 보관됩니다.

표지판을 동영상이나 사진으로 공유하려면?

전체 화면에서 … 메뉴를 열고 ‘동영상으로 공유’(한 번 반복, 1080p) 또는 ‘포스터로 공유’(정지 이미지)를 선택하세요. 둘 다 iOS 기본 공유 시트가 열립니다.

Siri를 쓸 수 있나요?

네. "Flaspek에서 내 표지판 표시"는 마지막 메시지를 보여 주고, "Flaspek에서 라이브 시작"은 라이브 세션을 시작합니다. 둘 다 단축어 앱에도 나타납니다.

Flaspek Pro를 해지하거나 복원하려면?

주간 플랜은 iPhone 설정 → 내 이름 → 구독에서 해지하거나, 홈 화면 맨 아래의 Flaspek Pro 줄을 탭하고 ‘구독 관리’를 선택하세요. 새 휴대폰에서 구매를 복원하려면 같은 화면을 열고 ‘구매 복원’을 탭하세요. 평생 이용권은 한 번만 결제하는 구매이며 갱신되지 않습니다.

내 데이터를 삭제하려면?

모든 메시지, 즐겨찾기, 설정은 내 iPhone에만 저장됩니다. 앱을 삭제하면 모두 삭제됩니다. Flaspek에는 계정도, 분석 도구도, 추적도 없습니다.
